# Исправление проблемы 404 на Railway

## Проблема
Ошибка `404 (Not Found)` при обращении к `/auth/telegram` означает, что:
1. Изменения не задеплоены на Railway
2. Сервер не перезапущен после изменений
3. Не хватает переменных окружения

## Решение

### Шаг 1: Проверьте деплой на Railway

1. Откройте ваш проект на [railway.app](https://railway.app/)
2. Перейдите в раздел **Deployments**
3. Убедитесь, что последний деплой успешен (зеленая галочка)
4. Если деплой не был запущен автоматически:
   - Нажмите **Redeploy** или **Deploy**
   - Дождитесь завершения сборки

### Шаг 2: Проверьте переменные окружения

В разделе **Variables** должны быть:

```
BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_URL=postgresql://...
FRONTEND_URL=https://ваш-домен.netlify.app
PORT=3001 (опционально, Railway сам назначит)
```

**Важно:** Добавьте `FRONTEND_URL` если его нет!

### Шаг 3: Проверьте логи

1. Откройте раздел **Logs** в Railway
2. При запуске сервера должно быть:
   ```
   BOT_TOKEN exists: true
   Server running on port 3001
   ```
3. Если видите ошибки - исправьте их

### Шаг 4: Принудительный редеплой

Если изменения не применились:

1. В Railway нажмите на ваш сервис
2. Откройте вкладку **Settings**
3. Нажмите **Redeploy** или удалите и создайте сервис заново

### Шаг 5: Проверьте, что код в репозитории

Убедитесь, что файл `backend/src/index.ts` содержит:

```typescript
app.get('/auth/telegram', async (req, res) => {
    // ... код обработки
});
```

### Шаг 6: Проверьте Railway конфигурацию

Убедитесь, что `railway.json` указывает на правильный Dockerfile:

```json
{
    "build": {
        "builder": "DOCKERFILE",
        "dockerfilePath": "Dockerfile"
    }
}
```

И что Railway настроен на папку `backend/` как root directory.

## Быстрая проверка

После всех шагов откройте в браузере:
```
https://rostanuz-production.up.railway.app/
```

Должно показать: `Rostan API is running`

Затем проверьте:
```
https://rostanuz-production.up.railway.app/auth/telegram
```

Без параметров должно вернуть ошибку `Missing auth data` (это нормально, значит роут работает).

## Если проблема осталась

1. Проверьте логи Railway на наличие ошибок компиляции
2. Убедитесь, что TypeScript компилируется без ошибок
3. Проверьте, что `dist/index.js` содержит роут `/auth/telegram`
4. Попробуйте пересоздать сервис на Railway
