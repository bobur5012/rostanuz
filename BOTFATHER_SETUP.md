# Настройка домена в BotFather (ОБЯЗАТЕЛЬНО!)

## Проблема
Ошибка `NOT_AUTHORIZED` означает, что домен не настроен в BotFather. Telegram виджет **НЕ БУДЕТ РАБОТАТЬ** без настройки домена.

## Решение

### Шаг 1: Откройте BotFather
1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/botfather)
3. Начните диалог с ботом

### Шаг 2: Настройте домен
1. Отправьте команду: `/setdomain`
2. BotFather покажет список ваших ботов
3. Выберите бота: **uslugiuz_bot** (или ваш бот)
4. BotFather спросит: "Please choose a domain for your bot"
5. Введите ваш домен:
   - Для продакшена: `rostanuz.netlify.app` (без https://)
   - Для локальной разработки: `localhost` (но это не всегда работает)

### Шаг 3: Проверка
После настройки BotFather ответит:
```
Success! Domain updated. You can now use this domain for your bot.
```

### Шаг 4: Перезагрузите страницу
После настройки домена:
1. Перезагрузите страницу с виджетом
2. Виджет должен загрузиться и показать кнопку "Log in with Telegram"

## Важно!

- Домен должен быть **БЕЗ** `https://` и `http://`
- Домен должен быть **БЕЗ** слеша в конце
- Для Netlify используйте формат: `rostanuz.netlify.app`
- Для локальной разработки используйте: `localhost` (но это может не работать)

## Если не работает

1. Проверьте, что домен введен правильно (без протокола)
2. Убедитесь, что вы выбрали правильного бота
3. Попробуйте удалить домен и добавить заново:
   - `/deletedomain` → выберите бота
   - `/setdomain` → выберите бота → введите домен

## Альтернатива для локальной разработки

Если `localhost` не работает, используйте:
- ngrok для создания туннеля
- Или используйте только `onAuth` callback (но виджет все равно может не загрузиться)
