# Инструкция по деплою (Railway & Netlify)

Проект разделен на две части: **Backend** (Railway) и **Frontend** (Netlify).

## 1. Деплой Бэкенда на Railway

1.  Создайте аккаунт на [railway.app](https://railway.app/).
2.  Нажмите **New Project** -> **GitHub Repo** и выберите свой репозиторий.
3.  Railway автоматически определит Node.js.
4.  В разделе **Variables** (Переменные окружения) добавьте:
    *   `PORT`: `3001` (или оставьте пустым, Railway сам назначит)
    *   `BOT_TOKEN`: Ваш токен телеграм бота.
    *   `YANDEX_MAPS_API_KEY`: Ваш ключ Яндекс.Карт.
    *   `DATABASE_URL`: Railway может создать базу данных PostgreSQL для вас. Если вы создадите её внутри проекта Railway, переменная `DATABASE_URL` добавится автоматически.
5.  В разделе **Settings** включите "Generate Domain", чтобы получить публичный URL (например, `rostan-production.up.railway.app`).
6.  **Хранение изображений**: Чтобы загруженные картинки не пропадали после обновления проекта (деплоя), добавьте в Railway **Volume** (Диск):
    *   Создайте Volume (например, на 1ГБ).
    *   Примонтируйте его по адресу `/app/backend/uploads` (или тому, где находится ваша папка uploads в Docker контейнере).
7.  **Важно:** Чтобы база данных заработала, в терминале (локально в папке `backend`) перед деплоем или через Railway CLI выполните:
    ```bash
    npx prisma db push
    ```
    (Это создаст таблицы в базе данных Railway).

---

## 2. Деплой Фронтенда на Netlify

1.  Создайте аккаунт на [netlify.com](https://www.netlify.com/).
2.  Нажмите **Add new site** -> **Import an existing project** -> **GitHub**.
3.  Выберите репозиторий.
4.  Настройки сборки:
    *   **Build command:** `npm run build`
    *   **Publish directory:** `dist`
5.  В разделе **Environment Variables** добавьте:
    *   `VITE_API_URL`: URL вашего бэкенда на Railway (например, `https://rostan-production.up.railway.app`).
6.  Нажмите **Deploy site**.

---

## 3. Настройка Телеграм Бота

1.  Напишите [@BotFather](https://t.me/botfather).
2.  Используйте команду `/setdomain`.
3.  Выберите вашего бота.
4.  Введите URL вашего фронтенда на Netlify (например, `https://rostan-app.netlify.app`). 
    *Это необходимо, чтобы виджет авторизации работал коректно.*

---

## Как это работает вместе "мощно"?

*   **TypeScript**: Типизация на фронте и бэке исключает ошибки.
*   **Prisma**: Быстрая и надежная работа с базой данных PostgreSQL.
*   **Авторизация**: Реальная проверка Telegram Hash на бэкенде защищает от поддельных входов.
*   **Синхронизация**: Все места, отзывы и избранное теперь сохраняются в базе данных, а не в памяти браузера.
